À propos

Une dev qui livre du code qui compte

Développeuse web full stack depuis plus de 3 ans, je travaille au quotidien sur une application métier utilisée par des milliers d'utilisateurs à l'international.

Mon terrain de jeu : le C#/.NET côté serveur et SQL Server (T-SQL) côté données. J'interviens sur toute la chaîne — nouveaux modules, évolutions, maintenance et correction de bugs — avec une exigence constante sur la qualité : code propre, sécurité et maintenabilité.

J'aime comprendre le besoin métier, le modéliser proprement et livrer des fonctionnalités fiables. Je travaille en équipe et j'attache de l'importance à la clarté du code autant qu'à sa robustesse.

Spécialiste .NET / C#, ouverte à d'autres langages et stacks.

Code métier

Sécurité

Travail d'équipe

Maintenabilité
